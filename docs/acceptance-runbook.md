# WaitBuddy 验收 Runbook（M1 + M3 核心 + 低调模式）

> **用途**：在 DSH 桌面端逐条验收当前版本，产出可复核的截图/录屏与结论。
> **范围**：M1 状态看板、M3 `agent:*` 信号/审批暂停/奖励、D27 移除推理原文、D28 question/plan 分 kind 告警（0.5.0 起可见）、低调模式（胶囊 / 浮动小窗 / 后台 + 系统通知，0.5.0–0.6.0）。
> **不覆盖**：M0 §10 的 M4 备选池、软按钮（D7 已批准偏离）。

---

## 1. 验收前准备

| 项 | 要求 |
|---|---|
| DSH 版本 | `0.2.1-rc.5`（当前唯一验证版本） |
| 插件 | 从本仓库目录安装/重载，刷新页面后能看到 WaitBuddy 标签 |
| 会话 | 新建一个测试会话，不要用含敏感信息的真实会话 |
| 权限 | 使用你日常的 permission preset；准备一个"会触发审批"的无害工具调用 |
| 证据 | 截图或录屏；记录 commit、DSH 版本、窗口尺寸 |
| 基线 | 对照 [M0](baseline-m0.md)；已知偏离见 [M0 对照](m0-compliance.md) |

**建议先跑自动化**：

```bash
npm test                 # 100 pass / 0 fail（纯逻辑 + 组件文案 + 五子棋 AI + 存在感/边界）
npm run test:visual      # 4 个无头浏览器布局场景（含宿主 tab bar / Todo dock / composer）
node --check index.js
node --check client.js
git diff --check
```

自动化覆盖纯逻辑（fold、compose、信号、暂停状态机、方向队列）、组件文案/按钮状态、以及 1200/320px 的静态布局。它**不能**覆盖真实 DSH 画布绘制、原生审批链路和双实例；这些仍需第 3 节的人工场景。

> 首次运行 `test:visual` 需要 Chromium：`npx playwright install chromium`（或使用已缓存的 Playwright 浏览器）。

## 2. 5 分钟 Smoke（先确认没坏）

1. 打开 WaitBuddy 标签：能看到状态行、活动流、棋盘，控制台无报错。
2. 点击「开始游戏」：蛇开始移动，方向键可用，分数/最高分显示。
3. 在对话里发一句简单任务（如"执行 `pwd` 然后总结"）：状态从 running 到 success，步数出现。
4. 切到 Chat 再切回 WaitBuddy：游戏暂停，浮层应写「视图切换后已暂停」，点击继续可恢复。
5. 活动流只出现「命令」/「工具」，**不出现「思考」或 reasoning 原文**。

Smoke 任意一项失败，先不要继续后续用例。

## 4. 判定标准

- **通过**：A1–A6、B1–B6、C1–C6、D1–D5、E1–E2、F1–F3、G1–G6 全部满足；B7/D4/F4/G7/G8 可标记"未验证"但需在记录里写明。
- **有条件通过**：核心路径通过，但视觉项（D1/D2/D3）或某条审批路径未验证；必须列出未验证项，不能声称"全部通过"。
- **不通过**：出现以下任一情况：
  - 活动流重新出现 reasoning 原文；
  - 审批出现时游戏不暂停，或审批结束后自动恢复；
  - 任务成功被显示成失败/未知，或未知结束原因显示成功；
  - 切会话后监控状态串到另一个会话；
  - 320px 出现横向滚动且核心按钮不可见；
  - 两个实例互相覆盖画布。

**已知偏离**（不按失败计，但必须记录）：

- D7：M0 §5 要求软按钮，当前无软按钮；已批准偏离。
- D16/D17：五子棋/设置属 M0 §10 M4 范围，提前实现；已批准偏离。
- D28：question/plan-review 自 0.5.0 起可见（分 kind 告警文案 + 游戏自动暂停 + 胶囊短语文案）。
- D22：未知终态用 `aborted` 承载，未新增 `unknown`；已按默认确认。

## 6. 常见问题

- **看不到审批**：确认 permission preset 会触发审批；WaitBuddy 只读 `pendingInteraction`，不拦截原生面板。
- **审批后游戏没恢复**：这是预期行为；M0 §9 要求用户手动点「继续」或按空格。
- **活动流没有「思考」**：D27 已移除 reasoning；这是预期行为，不是 bug。
- **切会话后显示「切换会话后已暂停」**：预期行为；点击继续即可。
- **320px 下设置消失**：窄窗容器查询会隐藏速度/难度，属于预期取舍；需要设置请拉宽视图。
- **双实例只有一个画布动**：先确认两个视图是否都挂载；若仍复现，记录为 RT-02 回归失败并附截图。
